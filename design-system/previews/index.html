Design-system recommendations for the Study app

Each row shows current (exactly what src/index.css ships) next to recommended (design-system/tokens.recommended.css), in all four palettes. Contrast ratios are computed live from the rendered colours. Details and reasoning: design-system/RECOMMENDATIONS.md. Current components: components.html.

≥ threshold below threshold · thresholds: 4.5:1 normal text, 3:1 large text (answer tiles are 28px+ extrabold)

DS-1 + DS-2 — text on coloured fills (CTA and correct tile)

CTA and correct-tile labels are a literal text-white. DS-1 adds --color-on-primary / --color-on-success so a palette can pick its own label colour (Deep Sea needs dark text). DS-2 deepens Wonder and Bubblegum green from #22c55e to #16a34a (Sunset already ships it).

DS-3 — secondary text on the screen background

--color-muted sits directly on --color-bg for path subtitles. It passes on white cards today, but not on the sky background.

DS-4 — idle answer tile in Deep Sea

The idle tile is a gradient from --color-bg-card to --color-primary-tint. Deep Sea never overrides the tint, so its tiles fade to near-white. The ratio shown is the label against the bottom of the gradient.

DS-5 — motion as tokens (no visual change)

Same values as today, read from variables instead of hard-coded in each @keyframes rule. Tap to replay. With reduced motion on, nothing moves, which is correct.

DS-6 / DS-7 — need art first

A bundled SVG icon set instead of emoji, and Tinku for loading, empty and error states. Neither has a preview yet, on purpose: both need art direction before anything is drawn. The mascot is never redrawn. See RECOMMENDATIONS.md.
